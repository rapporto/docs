Просмотр статистики рассылки
============================

После создания и запуска рассылки в личном кабинете есть возможность посмотреть статистику конкретной рассылки. Для этого необходимо перейти в раздел **"Рассылки"** на вкладку **"Отправленные"** и в списке рассылок нажать на строку с нужной рассылкой. Откроется страница с подробной информацией: прогресс, дата начала и окончания, скорость рассылки, расписание (если было задано), текст сообщения.

Если рассылка была прервана из-за технических проблем, есть возможность возобновить ее отправку, нажав на кнопку **<Возобновить>**. В этом случае все сообщения, отправка которых была отменена, вернутся в очередь на отправку.

Вкладка "Статистика"
---------------------

Во вкладке **"Статистика"** отображается информация по статусам сообщений рассылки:

* отправленных;

* доставленных;

* недоставленных;

* неотправленных.

.. note:: Недоставленное сообщение в случае каскадной отправки — сообщение, которое не удалось доставить ни по одному каналу.

Для SMS-рассылки выводится доля операторов, а также детализация количества отправленных, доставленных или недоставленных сообщений в разбивке по каждому оператору связи.

В случае Telegram-рассылки дополнительно отображается:

* общее количество абонентов, участвовавших в рассылке;

* информация о прочитанных сообщениях (число абонентов, увидевших хотя бы один показ);

* общее число прочитанных сообщений;

* общее число переходов по ссылке;

* среднее число показов на одного абонента;

* CTR — отношение общего числа переходов по ссылке к общему числу прочитанных сообщений. Измеряется в процентах.

Вкладка "Детализация"
----------------------

Для просмотра более детальной информации по определенной рассылке необходимо перейти на вкладку **"Детализация"** и нажать на кнопку **<Показать фильтры>**.
Далее на панели фильтров справа настроить отображение таблицы, выбрав нужные параметры:

* Телефон (включен по умолчанию);

* Канал — канал отправки сообщения;

* Направление — направление отправки; 

* Регион — регион абонента; 
  
* Статус — статус сообщения (включен по умолчанию);

* Части — количество частей в сообщении (только для SMS-рассылок);

* Показы — количество показов (только для Telegram-рассылок);

* Переходы — количество переходов (только для Telegram-рассылок);
  
* Подписки — количество подписок (только для Telegram-рассылок).

При необходимости возможно включить фильтрацию по статусам, направлениям, каналам и регионам, а также осуществить поиск по номеру телефона. Далее нажать на кнопку **<Получить данные>**.

Возможные значения статусов сообщений:

* "Ожидает отправки" — сообщение находится в очереди на отправку;

* "Отправлено" — сообщение отправлено абоненту;

* "Не отправлено" — сообщение не отправлено абоненту по техническим причинам;

* "Доставлено" — сообщение доставлено;

* "Не доставлено" — сообщение не доставлено абоненту;

* "Прочитано" — сообщение просмотрено абонентом (для каналов отправки Viber и Telegram).

Чтобы скачать детальную информацию, необходимо нажать на кнопку **<Скачать детализацию>** и выбрать нужный формат — .csv или .xlsx.

Вкладка "Повторная отправка"
-----------------------------

Во вкладке **"Повторная отправка"** отображается информация по параметрам повторной отправки рассылки в случае, если она была настроена при создании рассылки. 

Отображается следующая информация: 

* время жизни сообщения и действия в случае его истечения;

* статусы сообщений;

* дата и время повторной отправки.

При необходимости параметры повторной отправки можно редактировать, нажав на соответствующую кнопку.
