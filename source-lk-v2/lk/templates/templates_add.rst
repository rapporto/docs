Добавление шаблонов
====================

Для добавления новых шаблонов необходимо выполнить следующие действия:

.. image:: media/templates_add.gif

1. В личном кабинете перейти в раздел **"Шаблоны"**, нажав на соответствующую иконку в левом меню страницы.
2. В открывшемся разделе в правом верхнем углу нажать на кнопку **<Загрузить из файла>**.
3. В форме регистрации шаблона выбрать команду, для которой будут созданы шаблоны.
4. Нажать на область для загрузки и выбрать предварительно подготовленный :doc:`файл шаблона <templates_file>` в формате .xlsx.

   .. note::

      Блок **"Подсказка"** содержит краткое описание требований, предъявляемых к загружаемому шаблону, а также примеры оформления строк. Для сохранения файла с образцом на свой компьютер необходимо нажать на кнопку **<Скачать пример>** в левом нижнем углу. Рекомендуется использовать данный файл в качестве исходного для добавления собственных шаблонов.

5. Выбранный файл будет автоматически проверен на соответствие предъявляемым требованиям с последующим отображением результатов под областью для загрузки.

   .. note::
      
      Все загруженные файлы с шаблонами отображаются в виде списка под областью для загрузки. Для удаления элемента списка необходимо навести на него курсор и нажать на соответствующую кнопку.

6. В правом верхнем углу нажать на кнопку **<Отправить>**.

Загруженные файлы с шаблонами передаются операторам сотовой связи для проверки и регистрации. Отслеживание статусов шаблонов осуществляется через форму поиска в разделе **"Шаблоны"**.
