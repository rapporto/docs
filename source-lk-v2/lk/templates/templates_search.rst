Поиск шаблонов
================

Для поиска загруженных шаблонов необходимо выполнить следующие действия:

.. image:: media/templates_search.gif

1. В личном кабинете перейти в раздел **"Шаблоны"**, нажав на соответствующий пункт в левом меню.
2. На панели настроек выбрать команду, шаблоны которой необходимо найти.

   .. note::

      При отсутствии панели настроек необходимо нажать на кнопку **<Показать настройки>** в правом верхнем углу.

3. В поле **"Настройки таблицы"** указать колонки для отображения в результатах поиска.
4. Определить период активности шаблона. Возможные значения:

   * За все время;
   * Предыдущий месяц;
   * Текущий месяц;
   * Вручную – указать произвольный период.

5. В блоке **"Дополнительные фильтры"** при необходимости добавить фильтры по статусу шаблонов, оператору и типу трафика.
6. Нажать на кнопку **<Найти шаблоны>** для запуска поиска.

Поиск также может быть выполнен по тексту шаблона: в поле поиска необходимо ввести искомое значение, после чего нажать на кнопку с изображением лупы в правой части. В списке результатов отобразятся все шаблоны, текст которых содержит указанное значение.

Для сохранения результатов поиска в файл формата .xlsx необходимо нажать на кнопку **<Скачать список>** в правом верхнем углу.
