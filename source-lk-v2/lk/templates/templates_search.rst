Поиск шаблонов
================

Для поиска загруженных шаблонов необходимо выполнить следующие действия:

1. В личном кабинете перейти в раздел **"Шаблоны"**, нажав на соответствующую иконку в левом меню страницы.
2. В блоке настроек выбрать команду, шаблоны которой необходимо найти.
3. В поле **"Настройки таблицы"** указать колонки для отображения в результатах поиска.
4. Определить период активности шаблона. Возможные значения:

   * За все время;
   * Предыдущий месяц;
   * Текущий месяц;
   * Вручную – указать произвольный период.

5. В блоке **"Дополнительные фильтры"** при необходимости добавить фильтры по статусу шаблонов и типу трафика.
6. Нажать на кнопку **<Найти шаблоны>** для запуска поиска.

Для сохранения результатов поиска в файл формата .xlsx необходимо нажать на кнопку **<Скачать список>** в правом верхнем углу.
