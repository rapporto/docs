Проверка текста шаблона
==========================

Для проверки текста шаблона необходимо выполнить следующие действия:

.. image:: media/templates_check.gif

1. В личном кабинете перейти в раздел **"Шаблоны"**, нажав на соответствующий пункт в левом меню.
2. В открывшемся разделе в правом верхнем углу нажать кнопку **<Проверить текст>**.
3. В форме проверки текста шаблона ввести текст шаблона и пример сообщения. 
4. При необходимости развернуть блок **"Показать подсказку"**.
5. Нажать на кнопку **<Проверить>** для запуска проверки текста шаблона.

По итогам проверки отображается либо сообщение о соответствии текста шаблона примеру, либо рекомендации по устранению найденных несоответствий.

Для сброса формы проверки текста шаблона и повторного ввода нажать кнопку **<Очистить всё>**.
