Создание файла с шаблонами
============================

Базовые требования, предъявляемые к файлу с шаблонами:

* расширение файла: .xlsx, .csv;
* максимальное количество строк: 1000;
* кодировка: Windows-1251, UTF-8;
* максимальный размер файла: 1000 МБ;
* наличие строки заголовков;
* обязательные столбцы: **Сервисное имя**, **Оператор**, **Тип трафика**, **Шаблон**, **Пример шаблона**.

Описание столбцов таблицы в загружаемом файле:

+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **Наименование столбца**  | **Описание**                                                                                                                                                                                                                                                                                                      |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Внешний ID                | Идентификатор шаблона на стороне Партнера.                                                                                                                                                                                                                                                                        |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Сервисное имя             | Сервисное имя, для которого будет применяться шаблон.                                                                                                                                                                                                                                                             |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Оператор                  | Оператор сотовой связи, которому будет передан шаблон для регистрации.                                                                                                                                                                                                                                            |
|                           |                                                                                                                                                                                                                                                                                                                   |
|                           | Допустимые значения (без учета регистра):                                                                                                                                                                                                                                                                         |
|                           |                                                                                                                                                                                                                                                                                                                   |
|                           | * ``mts`` для МТС;                                                                                                                                                                                                                                                                                                |
|                           | * ``beeline`` для билайн;                                                                                                                                                                                                                                                                                         |
|                           | * ``megafon`` для МегаФон                                                                                                                                                                                                                                                                                         |
|                           | * ``tele2`` для T2;                                                                                                                                                                                                                                                                                               |
|                           |                                                                                                                                                                                                                                                                                                                   |
|                           | Список значений носит ознакомительный характер. Актуальную информацию о соответствии оператора и типа трафика уточняйте у своего менеджера.                                                                                                                                                                       |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Тип трафика               | Ожидаемый тип трафика.                                                                                                                                                                                                                                                                                            |
|                           |                                                                                                                                                                                                                                                                                                                   |
|                           | Допустимые значения (без учета регистра):                                                                                                                                                                                                                                                                         |
|                           |                                                                                                                                                                                                                                                                                                                   |
|                           | * ``service`` для сервисного трафика;                                                                                                                                                                                                                                                                             |
|                           | * ``information`` для информационного трафика;                                                                                                                                                                                                                                                                    |
|                           | * ``authentication`` для авторизационного трафика;                                                                                                                                                                                                                                                                |
|                           | * ``transaction`` для транзакционного трафика.                                                                                                                                                                                                                                                                    |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Шаблон                    | Текст шаблона с обязательным включением :doc:`выражений для автоподстановок <templates_expressions>`, которые отделяются от остальных элементов сообщения с помощью пробелов. Разбиение текста на абзацы не предусмотрено. Допускается использование одинаковых по содержанию шаблонов для разных сервисных имен. |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Пример шаблона            | Исходный текст шаблона с заменой всех выражений для автоподстановок на ожидаемые значения.                                                                                                                                                                                                                        |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Комментарий               | Дополнительная информация о шаблоне.                                                                                                                                                                                                                                                                              |
+---------------------------+-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
