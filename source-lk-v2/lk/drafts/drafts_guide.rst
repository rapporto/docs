Работа с разделом "Черновики"
==============================

Созданные черновики отображаются в разделе **"Черновики"** в личном кабинете. Информация о черновиках выводится в таблице со следующими параметрами:

* **"Название"** — наименование черновика;

* **"Текст"** — содержание черновика;

* **"Автор"** — пользователь, создавший черновик;

* **"Дата создания"** — дата и время создания черновика;

* **"Канал"** — тип сообщения, за которым закреплен черновик.

Если пользователь состоит в нескольких командах, слева от кнопки создания черновика находится поле для выбора команды из выпадающего списка. Подробнее о командах в статье :doc:`../../lk/teams`. 

Просмотр черновика
-------------------
Для просмотра содержимого черновика необходимо кликнуть по нему левой кнопкой мыши.


Редактирование черновика
--------------------------
Для редактирования черновика необходимо кликнуть по нему левой кнопкой мыши и в открывшейся форме нажать на кнопку **<Редактировать>**.


Поиск черновика
-----------------
Поиск осуществляется по названию или тексту черновика с помощью поля над списком черновиков.


Удаление черновика
--------------------
Для удаления черновиков следует выделить нужные элементы (по отдельности или с помощью флажка "Выбрать все") и нажать на кнопку **<Удалить>** в правом верхнем углу.
