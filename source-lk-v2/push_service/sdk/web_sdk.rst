Веб SDK
============

Благодаря веб-приложениям пользователи получили возможность взаимодействовать с веб-контентом так же, как с нативными приложениями, включая получение push-сообщений. 

Для отправки веб push-сообщений необходимо интегрировать в веб приложение/PWA веб SDK.

Общий порядок внедрения SDK:

* добавление в веб-приложение/PWA файла конфигурации и библиотеки, скомпилированной в виде динамического фреймворка;
* проведение процесса инициализации механизма регистрации подписки на веб push-сообщения.

Минимальные версии поддерживаемых браузеров можно посмотреть `здесь <https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API#browser_compatibility>`_.

Если остались вопросы по работе веб SDK Rapporto, просим обращаться в `службу технической поддержки <https://doc.rapporto.ru/support.html>`_.
