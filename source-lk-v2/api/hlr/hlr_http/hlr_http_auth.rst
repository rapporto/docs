Подключение сервиса
=======================

Для подключения сервиса **Партнер** должен предоставить :term:`Сервис-провайдеру <Сервис-провайдер>` список IP-адресов, 
с которых необходимо разрешить доступ к интерфейсу.

Если интерфейс настраивается в режиме тестирования, дополнительно необходимо указать следующие параметры:

* предполагаемый объем тестов (количество отправляемых сообщений);
* период тестирования, по окончании которого будет принято решение об использовании, либо не использовании интерфейса.


**Сервис-провайдер** предоставляет :term:`Партнеру <Партнер>` URL для отправки HLR-запросов.


По вопросам доступа следует обратиться в :ref:`Службу технической поддержки <support>`.
