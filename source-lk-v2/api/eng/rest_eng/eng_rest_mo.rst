
Mobile Originated Messages
==============================

Mobile Originated Message (MO message) is sent to the Partner's configured URL.

.. tabs::

   .. group-tab:: SMS

      **Request example**

      .. code-block:: json
         :linenos:

          { 
            "transactionId": "20190418175651967013", 
            "destAddr": "0000", 
            "sourceAddr": "72101234567", 
            "type": "SMS", 
            "message": "A message for the Partner", 
            "partCount": 1,
            "receivedDate": "2022-06-22T10:22:45+0300" 
          }

.. tabs::

   .. group-tab:: SMS

      **Request parameters**

      +-----------------------+--------------+--------------------------------------------------------------------+
      | Parameter             | Type         | Description                                                        |
      +=======================+==============+====================================================================+
      | transactionId         | string       | Transaction ID generated by the Service Provider system.           |                                        
      +-----------------------+--------------+--------------------------------------------------------------------+
      | destAddr              | string       | Service number where the subscriber sent the message to.           |
      +-----------------------+--------------+--------------------------------------------------------------------+
      | sourceAddr            | string       | Subscriber's number.                                               |
      +-----------------------+--------------+--------------------------------------------------------------------+
      | type                  | string       | Type of message. You should specify: SMS.                          |
      +-----------------------+--------------+--------------------------------------------------------------------+
      | message               | string       | Message text from subscriber to the Partner.                       |
      +-----------------------+--------------+--------------------------------------------------------------------+
      | partCount             | integer      | Amount of message parts                                            |
      +-----------------------+--------------+--------------------------------------------------------------------+
      | receivedDate          | string       | Date of which this MO message was received from the subscriber.    |
      +-----------------------+--------------+--------------------------------------------------------------------+
