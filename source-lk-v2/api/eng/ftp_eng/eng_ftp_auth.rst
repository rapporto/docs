
Setup
=============

For FTP API integration, the Partner shall provide the Service Provider with a list of IP addresses from which the connection is planned, as well as
coordinate with the personal manager: 

- the company name(s) or brand used as the sender ID in messages sent to users;
- available traffic directions;
- the volume of test messages (if a test period is required).

The Service Provider provides the Partner with the following data:

- login;
- password.


For access inquiries, please contact :ref:`the Technical Support <eng-support>`.
