
HLR
=======
 
.. toctree::
   :maxdepth: 1
   :hidden:

   hlr_http/hlr_http_main



Сервис :term:`HLR` может предоставить по запросу данные обо всех абонентах, зарегистрированных в сети оператора сотовой связи. Например, информацию о подписке, активных услугах, состоянии счета и текущем местоположении абонента.
