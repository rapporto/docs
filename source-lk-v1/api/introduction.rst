Типы сообщений, поддерживаемые в API
-------------------------------------

+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| Тип сообщения                                                          | REST         | HTTP         | SMPP         | REST_BATCH   |
+========================================================================+==============+==============+==============+==============+
| :abbr:`SMS (SMS)`                                                      | **Да**       | **Да**       |  **Да**      |  **Да**      |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| :abbr:`PUSH (Push-уведомление)`                                        | **Да**       | **Да**       |  **Да**      |  Нет         |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| :abbr:`VK (ВКонтакте)`                                                 | **Да**       | **Да**       |  **Да**      |  Нет         |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| :abbr:`VIBER (Viber)`                                                  | **Да**       | **Да**       |  **Да**      |  Нет         |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| :abbr:`FLASHINGCALL (Звонок на телефон абонента, при котором последние | **Да**       | **Да**       |  **Да**      |  Нет         |
| цифры номера вызываемого абонента рассматриваются в качестве кода)`    |              |              |              |              |

| :abbr:`CARDSMOBILE (Относится только к приложению “Кошелёк“)`          | **Да**       | Нет          |  Нет         |  Нет         |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+
| :abbr:`MAX (Max)`                                                      | **Да**       | Нет          |  Нет         |  Нет         |

| :abbr:`TELEGRAM (Telegram)`                                            | **Да**       | Нет          |  Нет         |  Нет         |

| :abbr:`TGCODE (Цифровой авторизационный код, отправляемый в Telegram)` | **Да**       | Нет*         |  Нет*        |  Нет         |
+------------------------------------------------------------------------+--------------+--------------+--------------+--------------+

.. note::

    На данный момент отправка абонентам в мессенджер Telegram цифровых авторизационных кодов по протоколам ``HTTP`` и ``SMPP`` возможна через Telegram Gateway. В запросе, при этом, необходимо указывать тип сообщения только ``SMS``. В процессе обработки сообщения будут конвертированы в TG-формат и переданы в Telegram.
