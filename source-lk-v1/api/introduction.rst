.. important::
   **Примечание по передаче кодов в мессенджер Telegram**

   В текущей реализации присутствует возможность отправки абонентам в мессенджер Telegram цифровых авторизационных кодов по протоколам ``HTTP`` и ``SMPP``. В запросе, при этом, необходимо указывать тип сообщения только ``SMS``. В процессе обработки сообщения будут конвертированы в TG-формат и через Telegram Gateway переданы в Telegram.

   Из-за ограничений в обработке статусов данный способ отправки не рекомендуется. 

   Для передачи Telegram-кодов и гибкого управления процессом верификации Партнеру следует использовать ``REST API`` с типом ``TGCODE``.
