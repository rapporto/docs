.. note::

    На данный момент присутствует возможность отправки абонентам в мессенджер Telegram цифровых авторизационных кодов по протоколам ``HTTP`` и ``SMPP``. В запросе, при этом, необходимо указывать тип сообщения только ``SMS``. В процессе обработки сообщения будут конвертированы в TG-формат и через Telegram Gateway переданы в Telegram.

    Из-за особенностей отправки таких сообщений и получения статусов данный способ отправки не получает развития и не рекомендуется. 

    Для передачи абоненту в мессенджер Telegram авторизационного кода  и гибкого управления процессом верификации Партнеру следует выбрать ``REST API``, в котором использовать тип сообщения ``TGCODE``.
