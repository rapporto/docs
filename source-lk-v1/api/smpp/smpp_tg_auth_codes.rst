Коды авторизации Telegram Gateway
==================================

В данном разделе приведено описание особенностей передачи авторизационных кодов по протоколу SMPP в Telegram Gateway. 

.. raw:: html

     <details>
         <summary>Подробнее</summary>
         <p>
             Сервис Telegram Gateway предназначен для доставки пользователям мессенджера Telegram авторизационных и верификационных цифровых кодов.
         </p>
         <p>
             Отправка кодов происходит от имени официального канала Verification Codes.
         </p>
         <p>
             Если пользователь скрывает свой номер телефона в настройках Telegram, это не влияет на доставку сообщения.
             Также на доставку кодов не влияет наличие или отсутствие у пользователя подписки Telegram Premium.
         </p>
         <p>
             Отправка цифровых кодов в сообщениях Telegram возможна в текстах сообщений любого типа. В процессе обработки сообщения будут конвертированы в TG-формат и переданы в Telegram. 
         </p>
         <p>
             На данный момент сервис поддерживает:
         </p>
         <ul>
             <li>отправку сообщений с кодами авторизации через Telegram;</li>
             <li>получение статусов доставки сообщений;</li>
             <li>каскадную передачу сообщений на альтернативные каналы в случае недоставки в Telegram (при необходимости).</li>
         </ul>  
     </details>


Подключение 
---------------

Подключение сервиса осуществляет :ref:`служба технической поддержки <support>` Сервис-провайдера. 

Для подключения Партнеру и Сервис-провайдеру необходимо согласовать данные:

- сервисное имя для передачи авторизационного кода в Telegram;
- время жизни сообщения (ttl).


Запрос на отправку 
-------------------

В запросе на передачу авторизационного кода в Telegram (в т.ч. в основном канале при каскадной отправке) необходимо указывать сервисное имя, 
отдельно согласованное со :ref:`службой технической поддержки <support>`. 

В запросе рекомендуется указать параметры и значения, относящиеся к типу сообщения ``SMS``.

Сообщение должно содержать код от четырёх до восьми цифр.

Для отправки сообщения Партнёру следует :ref:`установить соединение <linkSetting>` с сервером и передать Сервис-провайдеру пакет ``submit_sm``, 
в котором содержатся все необходимые параметры сообщения (опционально, также и :abbr:`TLV (Tag Length Value)`-параметры).

Ответ на запрос 
------------------

На пакет ``submit_sm`` сервер Сервис-провайдера отвечает пакетом ``submit_sm_resp`` с полем ``command_status``.

Если пакет принят и обработан успешно, тело пакета ``submit_sm_resp`` будет содержать ``message_id`` — уникальный идентификатор (целое положительное число), 
присвоенный на сервере Сервис-провайдера данному PDU. 

В дальнейшем значение ``message_id`` используется Партнёром для получения и анализа статусов доставки сообщения.

Возможные значения поля ``command_status`` приведены в таблицах ниже.

Ответ при успешной отправке
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В случае успешной отправки возвращается код ответа (HEX) ``0x00``.
          
+---------------------+-----------------------------------------------------+---------------------------------------------------------+
| Код (HEX)           | Описание                                            | Действие Партнёра                                       |
+=====================+=====================================================+=========================================================+
| 0x00                | Пакет принят успешно.                               | Ошибок нет, штатная работа сервиса.                     |
+---------------------+-----------------------------------------------------+---------------------------------------------------------+

~~~~~~~~~~~~~~~~~~~~~~

|                     |                                                     | повторить попытку отправки сообщения.                   |

Статусы доставки сообщений
----------------------------

Для получения статусов SMS-сообщений необходимо настроить :doc:`smpp_status`.

.. important::

   При отправке абоненту в мессенджер Telegram авторизационных кодов возможно получение только следующих статусов:

   - "доставлено";
   - "не доставлено".


Каскадная отправка
--------------------

:term:`Каскадная рассылка` сообщений по умолчанию недоступна. Для подключения Партнёру необходимо обратиться к курирующему менеджеру.

При каскадной отправке в запросе следует указывать параметры и значения, относящиеся к типу ``SMS``, в основном сообщении и в следующем сообщении в цепочке.      

Порядок доотправки сообщений передается в TLV-параметре ``cascade_order``, id = ``0x1444``.

Кроме того, есть возможность передавать требуемые опции каскада, используя дополнительные TLV-параметры пакета. 

Если сообщение передаётся разбитым на части, то TLV-параметры необходимо передавать во всех его частях.
