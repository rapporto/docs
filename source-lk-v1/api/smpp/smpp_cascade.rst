Каскадная рассылка
=====================

:term:`Каскадная рассылка` сообщений по умолчанию недоступна. Для подключения Партнёру необходимо обратиться к курирующему менеджеру.

Типы сообщений, допустимые в каскадной рассылке:

* FlashingCall (Voice Code);
* Push;
* SMS;
* Viber;
* VK.
