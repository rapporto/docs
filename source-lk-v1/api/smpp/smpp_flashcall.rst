FlashingCall (VoiceCode)
===========================

Запрос на отправку
=======================

Для отправки сообщения с типом :term:`FlashingCall` Партнёру следует :ref:`установить соединение <linkSetting>` с сервером и передать Сервис-провайдеру пакет ``submit_sm``, 
в котором содержатся все необходимые параметры сообщения (опционально, также и :abbr:`TLV (Tag Length Value)`-параметры). 

.. note:: При необходимости использования дополнительного функционала следует указать значения соответствующих TLV-параметров, описание которых приведено в следующем разделе сайта: :doc:`smpp_cascade`.


Для отправки :term:`VoiceCode` необходимо указать тип сообщения :term:`FlashingCall` и передать запрос, содержащий код. 

Указанный код (без сопутствующего текста) будет передан оператору, который вставит его в текст шаблона сообщения. 


Результат запроса FlashingCall
--------------------------------

| Результатом выполнения запроса :term:`FlashingCall` будет звонок на телефон абонента со специальной номерной ёмкости. 
| Последними цифрами номера вызывающего абонента является код, который передается в тексте сообщения. 
| Передаваемый код будет состоять либо из четырёх, либо из шести цифр. По умолчанию настроена передача четырёхзначного кода. Для настройки передачи шестизначного кода следует обратиться в службу технической поддержки Сервис-провайдера.
| Интервал ожидания ответа (ttl) о совершении звонка — от 1 до 5 минут.
| После отправки сообщения Сервис-провайдер синхронно возвращает ответ.


Результат запроса VoiceCode
----------------------------

Результатом запроса :term:`VoiceCode` будет звонок на телефон абонента. Когда абонент снимет трубку, он услышит голосовое сообщение, которое будет содержать код из четырёх цифр.

Ответ на запрос 
================

На пакет ``submit_sm`` сервер Сервис-провайдера отвечает пакетом ``submit_sm_resp`` с полем ``command_status``.

Если пакет принят и обработан успешно, тело пакета ``submit_sm_resp`` будет содержать ``message_id`` — уникальный идентификатор (целое положительное число), 
присвоенный на сервере Сервис-провайдера данному PDU. 

В дальнейшем значение ``message_id`` используется Партнёром для получения и анализа статусов доставки сообщения.

Возможные значения поля ``command_status`` приведены в таблицах ниже.


Ответ при успешной отправке
----------------------------

В случае успешной отправки возвращается код ответа (HEX) ``0x00``.
          
+---------------------+-----------------------------------------------------+---------------------------------------------------------+
| Код (HEX)           | Описание                                            | Действие Партнёра                                       |
+=====================+=====================================================+=========================================================+
| 0x00                | Пакет принят успешно.                               | Ошибок нет, штатная работа сервиса.                     |
+---------------------+-----------------------------------------------------+---------------------------------------------------------+

Статусы доставки 
======================

Для получения статусов FlashingCall (VoiceCode)-сообщений необходимо настроить :doc:`smpp_status`.

Коды ошибок доставки
------------------------

Коды ошибок доставки, в зависимости от типа сообщения, приведены в соответствующей вкладке в разделе :ref:`SMPP-ErrCodeDescr`.
