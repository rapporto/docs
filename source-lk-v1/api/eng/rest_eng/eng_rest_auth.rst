Setup
=======


For REST API integration, the Partner shall provide the following data to the Service Provider:

*  a set of IP subnets of the Partner (both an address and a mask of each subnet);
*  the company name(s) or brand used as the sender ID in messages sent to users;
*  URL for receiving :doc:`delivery statuses <eng_rest_status>`;
*  URL for receiving :doc:`MO messages <eng_rest_mo>`;
*  :ref:`the following data <eng-Rest-Setup>` to enable :doc:`eng_rest_short_link`. 


The Service Provider provides the Partner with the following data:

*  URI;
*  login;
*  password.

To protect the service, the *Basic access authentication* is supported.

For access inquiries, please contact the :ref:`Technical Support <support>`.
