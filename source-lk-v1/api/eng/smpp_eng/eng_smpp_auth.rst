Service Setup
========================

For the SMPP API integration, the Partner shall provide the following data to the Service Provider:

- a set of IP subnets of the Partner (both an address and a mask of each subnet);
- the company name(s) or brand used as the sender ID in messages sent to users.


The Service Provider provides the Partner with the following data:

- system_id;
- password;
- host and port — connection settings.


Please contact the :ref:`Technical Support Service <eng-support>` for access inquiries.
