Setup
==============

For HTTP API integration, the Partner shall provide the following data to the Service Provider:

* a set of IP subnets of the Partner (both an address and a mask of each subnet);
* the company name(s) or brand used as the sender ID in messages sent to users;
* URL for receiving :doc:`delivery statuses <eng_http_status>` (an option);
* URL for receiving :doc:`MO messages <eng_http_mo>` (an option);
* the :ref:`following data <eng-http-setup>` to enable :doc:`eng_http_short_link` (an option). 

The Service Provider provides the Partner with the following data:

* URL for sending HTTP requests;
* URI;
* serviceId;
* password.

For access inquiries, please contact :ref:`the Technical Support <support>`.
