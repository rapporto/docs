Setup
==============

To set up the service, the Partner must provide the following data to the Service Provider:

* a set of the Partner's IP-subnets (both IP-address and mask of each subnet);
* the company name(s) or brand used as the sender ID in messages sent to users;
* URL for receiving delivery statuses (:doc:`eng_http_status` is connected optionally).


The Service Provider provides the Partner with the following data:

* :term:`URL` for sending HTTP requests;
* :term:`URI`;
* :term:`serviceId`;
* :term:`pass`.


For access inquiries, please contact :ref:`the Technical Support <support>`.
