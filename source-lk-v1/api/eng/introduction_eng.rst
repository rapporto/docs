.. raw:: html

  <div class="admonition important">
       <p class="admonition-title">Important</p>
      <p><b>Note on Telegram Code Delivery</b></p>
      <p>Currently, the implementation supports sending digital authorization codes to subscribers via the Telegram messenger using the <code>HTTP</code> and <code>SMPP</code> protocols. In such requests, the message type must be specified as <code>SMS</code> only. The messages will then be converted to the TG format during processing and delivered to Telegram via Telegram Gateway.</p>
      <p>Due to limitations in status processing, this sending method is not recommended.</p>
      <p>For sending Telegram codes and flexible verification management, the Partner is advised to use the <code>REST API</code> with the <code>TGCODE</code> type.</p>
  </div>
