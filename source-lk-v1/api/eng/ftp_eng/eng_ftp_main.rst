:abbr:`FTP (File Transfer Protocol)` API v.5.0 is is designed to be used as a file sharing interface for creating SMS mass messaging.

Functional features
----------------------------

FTP API provides the following ability:

* an authorized Partner can automatically create and, if he has the appropriate privileges, start a mass messaging by uploading a file of the specified format to the Platform;
* automatically add the black list of numbers associated with the partner's account;
* download mass messaging with identifiers. This option is enabled upon request and applies simultaneously both to messaging downloaded via the file interface and to messaging created at a personal account.
