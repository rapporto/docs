
General file requirements
===============================

| Each file must have a unique name.

| The first letter of the file name must match the type of operation:

- S – mass messaging uploading;
- B – adding to the black list;
- SID – uploading of mass messaging with identifiers.
  
| During the recording process, the file must have the “.loading” extension.

.. note:: To avoid duplication of names, it is recommended to use the current system time in its name when creating a file, for example: “S20240310100000.loading”.

| Subscriber numbers must be recorded in the file in the international format. 

| For Russian cellular networks, the subscriber number consists of 11 digits and starts with 7.

| After the end of the recording, the extension should be changed to a “.data” extension. 

.. note:: After the change of the extension the contents of the file cannot be changed.
