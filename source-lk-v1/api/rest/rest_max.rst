MAX
==========

В разделе приведено описание особенностей передачи абонентам сообщений на устройства с установленным мессенджером MAX. 

.. raw:: html

     <details>
         <summary>Описание</summary>
         <p>
             В мессенджере MAX у Партнёров есть возможность взаимодействовать со своими клиентами через бота. Для этого пользователь должен активировать бота Партнёра. 
         </p>
         <p>
             Мессенджер MAX позволяет осуществлять рассылки только по идентификатору (id) пользователя, при этом, id пользователя не является его
             номером телефона. Это блокирует отправку Партнером индивидуальных (персонализированных) сообщений, например, информацию о транзакциях, статусах и т.д.
         </p>
         <p>
             Для решения данной задачи компания Rapporto разработала сервис MAX Gateway, позволяющий Партнерам осуществлять рассылки по номерам телефонов.
         </p>
         <p>
             На данный момент сервис поддерживает:
         </p>
         <ul>
             <li>отправку текстовых сообщений;</li>
             <li>получение статусов доставки сообщений;</li>
             <li>при необходимости, в случае недоставки в MAX - доотправку сообщений в SMS (каскадная передача).</li>
         </ul>  
     </details>

Ответ на запрос 
-----------------

После отправки сообщения Сервис-провайдер синхронно возвращает ответ. 

Ответ при успешной отправке 
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В случае успешной отправки возвращается HTTP-код ``200 OK``.

.. tabs::

    .. tab:: Пример ответа

      .. code-block:: json
         :linenos:

           {
              "mtNum": "MAX-ID-123"
              "id": "123"
           }


    .. tab:: Параметры ответа

      .. csv-table:: 
          :header: "Параметр", "Тип данных", "Описание"
          :widths: 30, 15, 35
          :class: my-table

          "mtNum", "string", "Идентификатор сообщения на стороне MAX-Gateway."
          "id", "string", "Идентификатор сообщения на стороне RCS, полученный в исходном запросе (параметр ``id``)."
          


Ошибки при отправке  
~~~~~~~~~~~~~~~~~~~~~~~~~~

Для ошибочных результатов HTTP-код ответа будет отличный от ``200 OK`` (см. :ref:`Коды-ошибок-отправки-max`).

.. tabs::

   .. tab:: Пример ответа

       .. code-block:: json   
          :linenos:

            {
                "error": {
                    "code": 8,
                    "description": "destAddr is not correct"
                },
                "extendedDescription": "Невалидный номер: 79999999999999999999999"
            }

   .. tab:: Параметры ответа

      .. csv-table:: 
        :header: "Параметр", "Тип данных", "Описание"
        :widths: 30, 15, 35
        :class: my-table

        "error", "object", "Информация об ошибке."
        "error/code", "int", "Код ошибки."
        "error/description", "string", "Краткое описание ошибки."
        "extendedDescription", "string", "Необязательный параметр. Содержит подробное описание ошибки."
