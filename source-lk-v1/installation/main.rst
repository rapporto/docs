Установка платформы On-Premises
=================================

Обеспечьте максимальный контроль и безопасность с помощью установки платформы On-Premises.

Система :doc:`rcs/inst_rcs` — готовое IT-решение для управления сервисами, которые позволяют взаимодействовать с пользователями через цифровые каналы коммуникации.

Система :doc:`pgw/inst_pgw` — готовое IT-решение по организации сервиса отправки Push-уведомлений, позволяющее достичь высоких показателей процента доставки сообщений и предоставить широкий перечень возможностей по передаче дополнительного контента (аудио, видео, deeplink и т. д.).
