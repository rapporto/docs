Что нового
==========

2025
----

Август
~~~~~~~~

В раздел "Интеграции" добавлена страница :ref:`Общая информация <introduction>`, которая содержит сводные таблицы с поддерживаемыми типами сообщений. Страница может помочь Партнеру при выборе интеграции.


Июль
~~~~~~

В REST API добавлен тип ``MAX`` для передачи абонентам :ref:`сообщений <rest-max>` в мессенджер MAX, в том числе, в каскадной рассылке.

Июнь
~~~~~~

В REST API добавлен тип сообщения ``TGCODE`` для передачи абонентам в мессенджер Telegram :ref:`авторизационных кодов <tg-codes>`, в том числе, в каскадной рассылке.

Апрель
~~~~~~~~

В REST API добавлено описание особенностей передачи абонентам :ref:`авторизационных кодов <tg-codes>` через платформу в Telegram Gateway.

Январь
~~~~~~~~

В раздел интеграции добавлено описание SMPP API.

В REST API добавлено :ref:`описание кодов ошибок <REST-ErrCodeDescr>` при недоставке Telegram-сообщений.

2024

Ноябрь
~~~~~~~

Обновлен дизайн сайта.
